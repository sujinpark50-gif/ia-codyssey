
# LEPI 서비스 기획서

## 1. 서비스 개요

**서비스명:** LEPI

LEPI는 사용자가 직접 작성한 게시글이나 메모의 **내용과 의미는 유지하면서 표현과 문장 흐름을 자연스럽게 다듬어 주는 AI 기반 글쓰기 보조 서비스**이다.

사용자가 SNS나 온라인 채널에 글을 게시하기 전에 초안을 입력하면, AI가 새로운 내용을 임의로 작성하는 것이 아니라 사용자가 작성한 원문을 기반으로 게시하기 좋은 형태로 정리해 준다.

현재 웹사이트는 LEPI 서비스를 소개하는 랜딩페이지와 함께 사용자가 AI 게시글 변환 기능을 직접 체험하고 무료 베타 서비스에 참여를 신청할 수 있도록 구성하였다.

---

## 2. 서비스 목적

SNS 게시글을 직접 작성하는 사용자는 전달하고 싶은 내용은 알고 있지만, 이를 자연스러운 문장으로 정리하거나 다른 사람이 읽기 좋은 형태로 만드는 과정에서 어려움을 느낄 수 있다.

LEPI의 목적은 사용자가 작성한 원문의 핵심 내용은 유지하면서 표현과 흐름을 다듬어 **실제로 게시할 수 있는 형태의 글을 보다 쉽게 완성하도록 돕는 것**이다.

특히 AI가 새로운 사실이나 내용을 대신 만들어주는 것보다 사용자가 직접 작성한 내용을 최대한 보존하면서 글의 완성도를 높이는 데 초점을 둔다.

---

## 3. 타겟 사용자

LEPI의 주요 타겟 사용자는 다음과 같다.

* SNS를 통해 상품, 서비스, 매장 등을 홍보하는 소상공인
* 게시글을 자주 작성하지만 문장 표현을 다듬는 데 어려움을 느끼는 사용자
* 생각이나 메모는 쉽게 작성하지만 게시 가능한 글로 정리하는 과정이 부담스러운 사용자
* AI가 글 전체를 새로 작성하기보다 자신의 원문과 의도를 유지하기 원하는 사용자

현재 구현 단계에서는 별도의 회원가입 없이 웹사이트에서 직접 AI 변환 기능을 테스트할 수 있도록 구성하였다.

---

## 4. 페이지 구성

현재 서비스는 하나의 랜딩페이지 안에서 서비스 소개, AI 기능 테스트, 무료 베타 신청 등의 기능을 제공한다.

| 구역       | 주요 내용                             |
| -------- | --------------------------------- |
| 메인 영역    | LEPI의 핵심 메시지와 서비스 목적을 소개          |
| 문제 제시    | 사용자가 게시글을 작성하면서 겪는 어려움을 설명        |
| 서비스 소개   | LEPI가 사용자의 글을 어떻게 다듬는지 설명         |
| 기능 소개    | 서비스의 주요 특징과 이용 방법 안내              |
| AI 테스트   | 사용자가 자신의 게시글을 직접 입력하여 AI 변환 기능 체험 |
| 변환 결과    | AI가 다듬은 게시글 또는 오류 메시지 표시          |
| 무료 베타 신청 | 사용자가 정보를 입력하여 무료 베타 참여 신청         |
| FAQ      | 서비스와 관련된 주요 질문과 답변 제공             |

메인 화면의 **'내 게시글로 테스트'**를 통해 AI 테스트 영역으로 이동하여 실제 변환 기능을 체험할 수 있다.

**'무료 베타 신청하기'**를 통해서는 베타 신청 영역으로 이동하여 서비스 참여에 필요한 정보를 입력할 수 있도록 구성하였다.

## 5. 핵심 기능

### 5.1 AI 게시글 변환

사용자가 직접 작성한 게시글을 입력하면 AI가 원문의 핵심 내용과 사실을 유지하면서 표현과 문장 흐름을 자연스럽게 다듬는다.

전체 처리 과정은 다음과 같다.

```text
사용자 게시글 입력
        ↓
JavaScript 입력값 확인
        ↓
fetch()를 통한 POST 요청
        ↓
Python API
        ↓
OpenAI API
        ↓
변환 결과 반환
        ↓
웹페이지 결과 출력
```

---

### 5.2 변환 결과 확인

AI 변환이 정상적으로 완료되면 페이지를 새로 불러오지 않고 같은 웹페이지에서 결과를 확인할 수 있다.

Python API에서 JSON 형식으로 결과를 반환하고 JavaScript가 해당 결과를 받아 변환 결과 영역에 표시한다.

---

### 5.3 무료 베타 신청

LEPI를 지속적으로 사용해보고 싶은 사용자가 랜딩페이지에서 무료 베타 참여를 신청할 수 있도록 신청 폼을 제공한다.

현재 신청 폼에서는 다음과 같은 정보를 입력받는다.

* 이름
* 이메일
* 활동 분야
* 개인정보 수집·이용 동의

필수 항목이 입력되지 않았거나 개인정보 수집·이용에 동의하지 않은 경우 신청을 완료하지 않고 사용자에게 필수 항목 입력을 안내한다.

현재 구현에서는 **프런트엔드의 입력값 검증과 신청 완료 표시까지 구현되어 있으며, 입력한 신청 정보를 실제 서버 또는 데이터베이스에 저장하는 백엔드 기능은 아직 연결하지 않았다.**

---

### 5.4 FAQ

사용자가 서비스를 이해하는 데 필요한 주요 질문과 답변을 제공한다.

FAQ 항목을 선택하면 해당 답변이 펼쳐지고, 다른 항목을 선택하면 기존 항목이 닫히도록 구성하여 한 페이지에서 필요한 정보를 쉽게 확인할 수 있도록 한다.

---

### 5.5 오류 및 예외 처리

AI 기능 이용 중 정상적인 결과를 받을 수 없는 상황을 고려하여 사용자에게 오류 안내 메시지를 제공한다.

주요 처리 대상은 다음과 같다.

* 게시글을 입력하지 않은 경우
* API 요청이 실패한 경우
* 서버에서 오류가 발생한 경우
* AI의 변환 결과가 비어 있는 경우
* 응답 시간이 지나치게 오래 걸리는 경우

# 6. AI 기능 정의

## 6.1 입력 기준

AI 기능의 입력값은 사용자가 직접 작성한 게시글 또는 메모 형태의 텍스트이다.

예시:

```text
우리 가게에서 오늘부터 여름 신메뉴를 판매해요.
아이스커피랑 같이 먹으면 좋아요.
많이 찾아주세요.
```

웹페이지의 JavaScript는 사용자가 입력한 내용을 JSON 형식으로 만들어 Python API에 전달한다.

```json
{
  "text": "사용자가 입력한 게시글"
}
```

빈 문자열이나 공백만 입력한 경우에는 OpenAI API를 호출하지 않고 입력 오류로 처리한다.

---

## 6.2 AI 처리 기준

AI는 입력된 원문의 의미를 유지하면서 문장 표현과 흐름을 자연스럽게 정리한다.

주요 처리 기준은 다음과 같다.

* 사용자가 작성한 핵심 내용과 의미 유지
* 문장 연결과 흐름 개선
* 어색한 표현을 자연스럽게 수정
* 가격, 날짜, 고유명사 등의 정보 임의 변경 금지
* 원문에 없는 새로운 정보 임의 추가 금지
* 사실을 과장하거나 변경하지 않음
* 사용자의 원문을 기반으로 결과 생성

즉 LEPI의 AI 기능은 **새로운 글을 처음부터 생성하는 것보다 사용자가 이미 작성한 글을 다듬는 것**에 초점을 둔다.

---

## 6.3 출력 기준

AI 처리가 정상적으로 완료되면 Python API는 HTTP 상태 코드 `200`과 함께 변환 결과를 JSON 형식으로 반환한다.

```json
{
  "result": "AI가 자연스럽게 다듬은 게시글"
}
```

웹페이지는 반환된 `result` 값을 받아 사용자에게 변환 결과로 표시한다.

AI의 분석 과정이나 별도의 설명을 출력하는 것이 아니라 **최종적으로 다듬어진 게시글을 결과로 제공하는 것**을 기준으로 한다.

---

## 7. AI 기능 실패 처리 기준

AI 기능은 사용자 입력, 네트워크, 외부 API 등의 영향을 받을 수 있으므로 실패 상황에 대한 처리 기준을 설정한다.

| 실패 상황              | 처리 기준                         |
| ------------------ | ----------------------------- |
| 입력값이 비어 있음         | API를 호출하지 않고 게시글 입력 요청 메시지 표시 |
| 잘못된 요청 데이터         | HTTP 400 오류와 요청 데이터 오류 메시지 반환 |
| OpenAI API Key 미설정 | HTTP 500 오류 처리                |
| OpenAI API 호출 실패   | 변환 중 오류가 발생했다는 메시지 표시         |
| AI 결과가 비어 있음       | 정상 결과로 처리하지 않고 오류 반환          |
| 응답 지연/타임아웃         | 일정 시간이 지나면 요청을 중단하고 사용자에게 안내  |
| 기타 서버 오류           | 내부 상세정보 대신 일반적인 오류 메시지 제공     |

사용자가 게시글을 입력하지 않은 경우 다음과 같이 안내한다.

```text
다듬을 게시글을 입력해 주세요.
```

API 또는 서버에서 문제가 발생한 경우에는 내부 오류 정보나 API Key 등의 민감한 정보를 사용자에게 노출하지 않고 다음과 같이 안내한다.

```text
게시글을 변환하는 중 오류가 발생했습니다.
```

## 8. 무료 베타 신청 입력 및 실패 처리 기준

### 입력 기준

무료 베타 신청에서는 이름, 이메일, 활동 분야와 개인정보 수집·이용 동의 여부를 확인한다.

필수 입력값이 모두 존재하고 개인정보 수집·이용에 동의한 경우에만 신청 완료 상태로 처리한다.

### 실패 처리

필수 정보가 누락되거나 동의 항목이 선택되지 않은 경우 다음과 같은 안내 메시지를 제공한다.

```text
필수 항목을 모두 입력해주세요.
```

현재 단계에서는 신청 데이터를 실제 서버 또는 데이터베이스에 저장하지 않으므로 데이터 저장 실패에 대한 백엔드 오류 처리는 구현 범위에 포함하지 않는다.

## 9. 서비스 전체 동작 흐름

### AI 게시글 변환

```text
사용자 웹사이트 접속
        ↓
게시글 입력
        ↓
'레피로 다듬기' 선택
        ↓
입력값 확인
        ↓
fetch()로 /api POST 요청
        ↓
Python API
        ↓
OpenAI API 호출
        ↓
AI 게시글 변환
        ↓
Python API가 JSON 반환
        ↓
JavaScript가 결과 수신
        ↓
변환 결과 화면 출력
```

### 무료 베타 신청

```text
사용자 웹사이트 접속
        ↓
'무료 베타 신청하기' 선택
        ↓
신청 영역으로 이동
        ↓
신청 정보 입력
        ↓
필수값 및 동의 여부 확인
        ↓
신청 완료 표시
```

## 10. 현재 구현 범위

현재 버전은 LEPI의 서비스 소개와 핵심 AI 기능을 실제 웹 환경에서 검증하기 위한 MVP 형태로 구현하였다.

현재 구현된 범위는 다음과 같다.

* LEPI 서비스 소개 랜딩페이지
* 서비스 페이지 및 메뉴 이동
* 사용자의 게시글 입력
* 실제 OpenAI API를 이용한 AI 게시글 변환
* 변환 결과 화면 출력
* 빈 입력값 처리
* API 및 서버 오류 처리
* 요청 타임아웃 처리
* 무료 베타 신청 폼
* 무료 베타 신청 입력값 검증
* FAQ 인터랙션
* GitHub를 통한 소스 코드 관리
* Vercel을 통한 웹 배포

현재 AI 게시글 변환 기능은 실제 OpenAI API와 연결되어 동작한다.

무료 베타 신청 기능은 **사용자의 입력과 프런트엔드 검증까지 구현된 상태이며, 신청 정보를 영구 저장하는 데이터베이스 및 백엔드 연동은 향후 구현 범위**로 둔다.

현재 단계의 핵심 목표는 **사용자가 웹사이트에 접속하여 자신의 게시글을 입력하고 AI가 변환한 결과를 실제로 확인할 수 있는 전체 흐름을 구현하는 것**이다.
