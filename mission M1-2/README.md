# ADAIR UGV AI Assistant

## 프로젝트 소개

산불재난대응 프로젝트(ADAIR)의 실제 UGV 주행 테스트 데이터를 활용하여, 주행 정보를 분석하고 자연어 질문에 답변하는 AI 비서 웹 애플리케이션입니다.

코디세이 **「AI Agent 개발: 나만의 AI 비서 구축」** 과제로 진행합니다.

## 주요 기능

- UGV 주행 속도 시계열 데이터 분석
- 평균·최대·최소 속도 및 최근 변화 확인
- GPT 기반 데이터 분석 채팅
- Firestore 데이터 추가·조회·수정·삭제
- AI 대화 기록 저장 및 불러오기

※ 현재 데이터 검증 단계이며, 웹 서비스 기능은 개발 예정입니다.

## 사용 데이터

- **출처:** ADAIR 산불재난대응 시뮬레이션
- **환경:** Gazebo + PX4
- **대상:** UGV 주행 속도 데이터
- **원본:** `B1x_slope_low_20261010_184532.csv`
- **데이터 규모:** 위치 관측값 8,079개, 파생 속도값 8,078개(Codex 조사 기준)
- **처리 방식:** 위치와 시뮬레이션 시간으로 속도를 계산하고 1초 단위로 집계

원본 데이터의 독립 검증과 정규화 작업은 진행 예정입니다.
